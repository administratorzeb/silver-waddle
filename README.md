## 🚀 Démarrage rapide

### 1. Cloner le projet
```bash
git clone https://github.com/administratorzeb/silver-waddle.git
cd silver-waddle
```

### 2. Ouvrir localement
Il suffit d'ouvrir le fichier `index.html` dans votre navigateur :
```bash
# Sur macOS
open index.html

# Sur Windows
start index.html

# Sur Linux
xdg-open index.html
```

Ou utilisez un serveur local :
```bash
# Avec Python 3
python -m http.server 8000

# Avec Node.js (http-server)
npx http-server
```

Puis accédez à `http://localhost:8000`

### 3. Déployer en ligne

#### Avec GitHub Pages
1. Poussez le code sur GitHub
2. Allez dans Settings → Pages
3. Sélectionnez la branche `main`
4. Votre site est publié !

#### Avec Netlify
1. Connectez votre repo GitHub
2. Déploiement automatique
3. Accédez à votre site en ligne

#### Avec Vercel
1. Importez votre projet
2. Configuration automatique
3. Déploiement instantané

## 🎨 Customisation

### Changer les couleurs
Modifiez les variables CSS dans `styles.css` :
```css
:root {
  --primary-color: #004080;
  --secondary-color: #0066cc;
  --accent-color: #ff6b6b;
  /* ... autres variables */
}
```

### Ajouter du contenu
Éditez les fichiers HTML pour ajouter vos propres sections, pages ou fonctionnalités.

### Modifier le style
Personnalisez `styles.css` selon vos préférences de design.
